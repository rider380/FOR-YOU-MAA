ALEKHYA PICHIDI — CINEMATIC LOVE WEBSITE

Files:
- index.html
- videos/clip01.mp4 through clip15.mp4

HOW TO PUBLISH ON GITHUB PAGES:
1. Open your GitHub repository (the one you used before: FOR-MY-PICHIDI).
2. Click Add file > Upload files.
3. Upload index.html and the entire videos folder with all 15 clips.
   If GitHub's browser uploader doesn't let you upload the folder, open videos on your computer,
   select all 15 clips, and drag them into the repository upload page. Keep their names exactly clip01.mp4 ... clip15.mp4.
4. Scroll down and click Commit changes.
5. Open Settings > Pages. Choose Deploy from a branch, branch main, folder /(root), then Save if not already set.
6. Wait a few minutes, then open your existing GitHub Pages website and refresh.

IMPORTANT:
- Keep the videos folder beside index.html. Don't rename the clip files unless you also edit index.html.
- This website does not autoplay sound; each reel has its own play controls.
- Google Fonts needs internet; if unavailable, the page falls back to built-in fonts.
- The clips are copied into this folder, so uploading this project publishes the actual videos with the page.
